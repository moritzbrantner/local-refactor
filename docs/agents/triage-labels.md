# Triage Labels

Canonical triage roles map to these exact GitHub label strings:

| Role | Label |
| --- | --- |
| Needs initial triage | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for agent implementation | `ready-for-agent` |
| Requires human implementation | `ready-for-human` |
| Will not be worked on | `wontfix` |

PRD issues use `prd`. Agent-loop runtime labels use the `agent-loop:*` prefix.
